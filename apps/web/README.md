# Table Read — web

React 18 + TypeScript + Vite + Tailwind. Part of the Table Read monorepo; run `make dev`/`make test`/`make lint` from the repo root.

- `npm run dev` — dev server on port 5173
- `npm run build` — typecheck + production build
- `npm test` — Vitest
- `npm run lint` — ESLint
- `npm run format:check` — Prettier check
